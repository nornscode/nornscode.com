Fulla sends reminders and follows up in chat

Message Fulla on Telegram, Signal, or SMS. Each reminder is a Norns run that waits until it’s due. The worker can shut down while Norns keeps track of the reminder.

What stays running

The hosted worker on Fly stops when it’s idle. Norns keeps the conversation and pending reminders, and wakes the worker when a timer fires or a reply arrives.

Fulla can use a separate worker on your Mac for Things, Reminders, and iMessage drafts. If the Mac is asleep, the task waits for it to reconnect. Invited contacts talk to a separate agent with no access to your calendar, reminders, or devices.

Run Fulla locally

The local worker stays running and uses Telegram. You’ll need Norns, an Anthropic API key, a Telegram bot token from @BotFather, and your numeric Telegram user ID. 

nornsctl dev
nornsctl dev status
git clone https://github.com/nornscode/fulla.git
cd fulla
cp .env.example .env
uv sync

Set your Telegram and Anthropic credentials in .env, along with the Norns URL and API key from nornsctl dev status. Then register the webhook that lets Norns send Fulla run updates. 

uv run --env-file .env fulla-register-channel --url http://localhost:9000

Save the returned secret as NORNS_WEBHOOK_SECRET in .env, then start Fulla.

uv run --env-file .env fulla

Send your Telegram bot /start, then try asking for a reminder.
