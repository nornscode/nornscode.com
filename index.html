Norns is the runtime for long-lived agents.

Each agent run in Norns is backed by a durable event log. Runs can last for months and survive restarts and crashes, making them ideal for critical agentic workloads.

Your workers make the model calls, run the tools, and store the keys. Norns orchestrates.

Quickstart View on GitHub

Run an agent locally

Use Homebrew to install the CLI and uv to run the Python worker.

brew install nornscode/tap/nornsctl
nornsctl dev
nornsctl new my-agent
cd my-agent
uv sync
uv run my-agent-worker

Once the worker connects, the Hello agent example shows how to send a message and inspect the run.

How runs survive

  1. Norns saves each message to the run’s durable event log.
  2. Your worker runs the tool. Norns logs the result and reuses the same idempotency key on retries.
  3. After a restart or a long wait for a timer or reply, the run resumes from its last checkpoint.
